# Privacy

ShopShift operates locally. It has no account, server, telemetry, analytics, automatic update check or network API. CSV/XLSX files, column mappings, calendars, scenarios and schedules stay in files chosen by the planner. The app does not read ERP credentials or send data to an ERP. Exported CSV/HTML and backup files contain planning information; share only the files you intend to share.

Project files and backups are plain UTF-8 JSON, not encrypted. Protect their folder using your operating system. The previous saved version is retained as `.bak`; deleting the main file does not delete a backup. Print and HTML/CSV exports are read-only snapshots and do not enforce access controls.

Synthetic examples contain invented shop orders and generic resource IDs. No real customer, employee or company data is bundled.
