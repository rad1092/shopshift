# v0.1 internal contract
Dataclasses in shopshift.model, JSON-friendly via explicit to_dict/from_dict helpers.
Window(start:int,end:int) half-open UTC epoch seconds. Resource(id:str, windows:list[Window]).
Operation(id:str, job:str, machine:str, operator:str='', setup:int=0, run:int=60, predecessors:list[str]=[], release:int|None=None, due:int|None=None, label:str=''). duration property = setup+run in seconds. All operations nonpreemptive; operator occupied for entire setup+run. Fixed machine/operator assignment, no sequence-dependent setup.
Placement(start:int, locked:bool=False). End derives from Operation duration, never stale cache.
Scenario(name:str, placements:dict[str,Placement]={}).
Project(name:str='Untitled', timezone:str='UTC', horizon_start:int=0, horizon_end:int=0, operations:dict[str,Operation]={}, machines:dict[str,Resource]={}, operators:dict[str,Resource]={}, scenarios:dict[str,Scenario]={'Baseline': Scenario('Baseline')}, active_scenario:str='Baseline', mappings:dict[str,dict[str,str]]={}). scenario property current Scenario. Project.to_dict(), Project.from_dict(data), clone via deepcopy.
validator.validate(project, scenario=None) -> list[Issue] with Issue(code:str, message:str, operation_ids:tuple[str,...]=(), severity:str='error'). Unscheduled is warning; malformed inputs error. Full API independent of Qt and ORtools. Validate timezone/horizon/resources/window ordering/dependency cycles and missing links before placements. Missing locks require errors; locks represented by existing Placement.locked.
solver.suggest(project, scenario=None, time_limit:float=5.0) -> SolveResult(status:str, placements:dict[str,Placement], issues:list[Issue], wall_time:float, objective:float|None, bound:float|None). Status optimal/feasible/time_limited/infeasible/invalid. Invalid existing unlocked placements shouldn't block rebuilding, but conflicting locks do. Don't mutate Project. Retain existing locks; limit one worker. Objective sum tardiness plus makespan (document weights), or simpler explicit single objective. Validate candidate separately before returning. None result -> empty placements; never apply partial schedule implicitly.
Import API shopshift.importing: read_table(path)->(headers:list[str], rows:list[dict[str,str]]); import_operations(project, path, mapping:dict[str,str], duration_unit:str='minutes')->ImportResult(project:Project, added:list[str], updated:list[str], retained:list[str], warnings:list[str]). Atomic copy; raises ImportProblem(message) on any corrupt row, duplicate IDs, missing columns etc. Mapping canonical fields -> source headers, fields id,job,machine,operator,setup,run,predecessors,release,due,label. Strict dates ISO with offset OR unambiguous local IANA datetime; reject DST gap/fold unless offset provided. Preserve all placements by stable ID including locks; do not remove omitted operations. New resource IDs get project default weekday 08-12/13-17 windows, explicitly noted in warnings. Saved mapping includes __duration_unit. XLSX formulas rejected; CSV UTF8 BOM, cap file and row count.
shopshift.storage save_project(project,path), load_project(path), backup_project(project,path) atomic replace+fsync, previous file path+'.bak', explicit recovery load backup; fail on corrupt JSON/schema. export_csv(project,path,day=None), export_html(project,path,day=None) print plan, warnings included and escape cells/formulas.
shopshift.timeutil parse_timestamp(value,timezone)->int, format_timestamp(epoch,timezone)->str, working_windows(start,end,timezone,start_hour=8,end_hour=17)->list[Window] (lunch 12-13; weekdays); accepts explicit offset for DST folds. UTC seconds no rounding dates.
Demo shopshift.demo.demo_project()->Project, path independent synthetic fixture.
CLI python -m shopshift or shopshift -> GUI; --smoke-test <output-dir> -> GUI widget tests, screenshot+smoke.json, exits nonzero on failure. --version. Separate headless API tests pytest.
